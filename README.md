# 词汇快刷

这是一个用于快速复习 GRE 和雅思词汇的网页工具。目前共有 6 套词库和 9,307 张词卡。

[打开在线版本](https://xuegao0305-droid.github.io/gre-fast-pass/)

## 词库

- GRE 等价词 905
- 雅思高级同义替换 114
- 雅思词汇真经 3,673
- 雅思写作词汇与词组 143
- GRE 急救高频 1,400
- GRE 3000 词 3,072

GRE 急救高频 1,400 是公开整理版，不是考满分官方词表。

## 使用方法

网页每次同时显示一个单词或词组和中文释义。按空格可以查看同义词、替换表达或其他补充。左右两侧的大按钮可以前后翻词。顶部进度条可以拖动到本轮的任意位置。

点击页面顶部的当前词库可以切换词库。每套词库会分别保存轮次、位置、学习范围和每个词的状态。你切换词库后，原来的进度不会丢失。

你可以使用全部词表或分组词表。你也可以在设置中输入开始和结束位置，自定义本轮学习范围。

你可以选择以下状态：

- 不认识。这个词会在下一轮优先出现。
- 认识。这个词会在不认识的词之后出现。
- 完全熟悉。这个词不会继续出现在后面的轮次中。

你也可以直接按 1、2、3 完成选择。按 Z 可以撤销上一次选择。

## 进度保存

网页会在每次选择后，把所有词库的当前轮次、所在位置和每个单词的状态保存在浏览器中。关闭网页或退出浏览器不会清空这些记录。

如果你要更换浏览器或设备，请先在设置中下载进度备份，再在新设备中导入。备份文件会包含所有词库的记录。

## 手机和电脑

网页同时适配手机和电脑。在手机浏览器中打开在线版本后，可以把它添加到主屏幕。安卓手机可以使用浏览器菜单中的安装应用。iPhone 请用 Safari 打开，然后选择分享和添加到主屏幕。

安装后可以像普通应用一样打开。打开过的页面和词表支持离线使用。

## 本地打开

`docs` 文件夹中是 GitHub Pages 使用的静态版本。你可以用任意本地网页服务器打开这个文件夹。

项目根目录中还保留了带云端数据库接口的版本。开发时需要 Node.js 22.13 或更新版本。

```bash
npm install
npm run dev
```
